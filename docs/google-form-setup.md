# Google Form · Sheets 설정 가이드 — "내 사례 남기기"

> 이 문서는 운영자(닥터마빈)가 Google 계정으로 직접 폼을 생성할 때 그대로 옮겨 넣을 수 있도록 작성했다.
> 폼·시트는 Google 계정 권한이 필요하므로 코드에서는 생성하지 않는다. 폼 발행 후
> **`src/ui.js` 상단 `CONFIG.CASE_FORM_URL`에 폼 URL을 입력하고 빌드·배포하면**
> 사이트의 모든 "내 사례 남기기" CTA가 자동으로 활성화된다 (비어 있으면 CTA 숨김 + 콘솔 경고).

## 1. 폼 제목
닥터마빈에게 부동산 고민 사연 남기기

## 2. 첫 화면 설명
부동산 세금은 같은 1주택자라도 취득 시기, 거주 여부, 주택 수, 공동명의 여부 등에 따라 결과가 크게 달라집니다.
계산기를 이용하다가 "내 경우에는 어떻게 해야 하지?"라는 고민이 생겼다면 아래에 상황을 남겨주세요.

모든 사연에 개별적으로 답변드리기는 어렵습니다. 다만 비슷한 질문이 반복되거나 많은 분들에게 도움이 될 만한
사례를 중심으로 선정하여 닥터마빈이 직접 검토하고, 유튜브 영상이나 블로그 등을 통해 답변드릴 예정입니다.

선정된 사연은 이름·연락처·구체적인 아파트명 등 개인을 특정할 수 있는 정보는 공개하지 않으며,
필요한 경우 일부 내용을 수정·축약하여 소개합니다. 따라서 실명, 전화번호, 상세주소, 아파트 동·호수 등
불필요한 개인정보는 사연에 작성하지 말아주세요. 아파트명도 꼭 필요한 경우가 아니라면
"서울 강동구 20억원대 아파트"처럼 범위를 넓혀 적어주세요.

아래 내용을 확인하고 동의하는 경우에만 사연을 남겨주세요.

## 3. 입력 항목
| # | 질문 | 유형 | 필수 | 선택지·검증 |
|---|---|---|---|---|
| 1 | 무엇이 가장 궁금하신가요? | 단일선택 | 필수 | 양도소득세 / 종합부동산세 / 취득세 / 증여 / 공동명의 / 갈아타기 / 기타 |
| 2 | 현재 주택 수 | 단일선택 | 필수 | 1주택 / 2주택 / 3주택 이상 |
| 3 | 주요 대상 주택 지역 | 단일선택 | 필수 | 서울 / 수도권 / 지방 — 여러 주택이면 이번 사연에서 가장 궁금한 주택 기준 |
| 4 | 현재 거주 여부 | 단일선택 | 필수 | 거주 / 비거주 / 향후 거주 예정 |
| 5 | 소유 형태 | 단일선택 | 필수 | 단독명의 / 부부공동명의 / 기타 공동명의 |
| 6 | 취득연도 | 숫자 | 필수 | 1970~2029 범위 검증 (Forms 응답 확인 규칙: 숫자, 사이 값) |
| 7 | 대략적인 취득가격 | 단답 | 필수 | 단위 안내 필수 — 예: "7억" 또는 "700,000,000원"처럼 단위를 붙여 작성 |
| 8 | 현재가격 또는 예상 매도가격 | 단답 | 필수 | 위와 동일한 단위 안내 |
| 9 | 현재 상황 설명 | 장문 | 필수 | 안내: "취득 시기, 거주기간, 주택 수 변화, 향후 계획 등 판단에 필요한 내용을 적어주세요. 실명, 전화번호, 상세주소, 동·호수는 작성하지 말아주세요." |
| 10 | 닥터마빈에게 가장 묻고 싶은 한 가지는 무엇인가요? | 장문 | 필수 | 사연 전체와 별도로 핵심 질문 1개 |
| 11 | 내용 확인을 위해 추가 연락을 받아도 괜찮다면 이메일을 남겨주세요 | 단답(이메일 검증) | 선택 | 전화번호는 수집하지 않는다 |

## 4. 동의 항목
**[필수] 사연 콘텐츠 활용에 동의합니다.**
제출한 사연은 개인을 특정할 수 있는 정보를 제외한 뒤 닥터마빈의 유튜브, 블로그, 카페 등 콘텐츠에서
소개·인용·요약·각색하여 사용할 수 있습니다.

**[필수] 개별 답변이 보장되지 않는다는 점을 확인했습니다.**
모든 사연에 개별적으로 답변드리지는 않으며, 반복적으로 접수되는 질문 또는 많은 분들에게 도움이 될 만한
사례를 중심으로 선정하여 콘텐츠로 답변할 수 있습니다.

**[선택] 이메일 수집·이용 동의** — 이메일을 실제로 입력한 경우에만 해당
- 수집 목적: 사연 내용 추가 확인
- 수집 항목: 이메일 주소
- 보유 및 이용 기간: **(확정 필요 — 운영자가 기간을 정해 기입할 것. 무기한 보유로 쓰지 말 것)**
- 동의를 거부할 수 있으며, 동의하지 않아도 사연 제출에 불이익이 없습니다. 이메일을 적지 않은 경우 이 동의는 필요하지 않습니다.

## 5. 응답 시트 관리 구조 (Google Sheets)
응답 시트 오른쪽에 관리 컬럼 추가:
`사연번호 · 분야 · 핵심질문 · 유사사연 수 · 흥미도 · 시의성 · 검증필요 · 콘텐츠선정 · 영상제작 · 공개일 · 처리상태 · 내부메모`

상태 흐름: `신규 → 검토 → 유사사례 통합 → 선정 → 제작중 → 영상화`

운영 권장:
- 분야별 필터 보기 + 핵심질문 검색(Ctrl+F 또는 필터 보기)
- 유사사연 수는 `COUNTIF`로 집계(핵심질문 키워드 기준)
- 콘텐츠선정 체크박스 열, 공개일은 날짜 형식으로 관리
- **개인정보(이메일·사연 원문)를 내부메모 열에 복사하지 않는다**

## 6. 사이트 연동 (개발 완료 상태)
1. 폼 발행 → "보내기" → 링크 복사 (`https://docs.google.com/forms/d/e/…/viewform`)
2. `src/ui.js`의 `CONFIG.CASE_FORM_URL`에 붙여넣기 → `bash build.sh` → `bash deploy.sh`
3. CTA는 결과 화면 하단(설명 블록)과 페이지 맨 끝(보조)에 자동 노출, 새 탭 + `rel="noopener noreferrer"`
4. 계산기 입력값은 폼 URL에 자동 첨부되지 않는다(개인정보·세금 정보 자동 전송 금지)
